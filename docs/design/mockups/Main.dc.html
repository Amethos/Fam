Built to stop scammers

Fake "tech support" uses remote-access apps. Ours only opens to family.

Closed family circle

Only devices you've linked can connect. There's no code a stranger can ask for.

24-hour safety wait

A newly linked helper can't take control for a day. Scams run on panic — this takes the panic away.
